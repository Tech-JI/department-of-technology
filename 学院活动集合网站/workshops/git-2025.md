# Git Workshop 基础与协作

技术部 Workshop · 2025 年秋季

## Workshop 介绍

这场 Workshop 从版本控制的用途讲起，通过基本命令学习记录、查看和管理项目改动。随后介绍如何用分支组织并行工作，以及怎样通过 GitHub 与他人协作。可以先完成安装和 SSH 配置，再用练习题巩固提交、分支和远程仓库的用法。
