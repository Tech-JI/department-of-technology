# Arch Linux 安装 Workshop

技术部 Workshop · 2026 年夏季

## Workshop 介绍

课程以 Arch Linux 安装和 Windows 双系统配置为主线，先解释电脑从开机到进入桌面的过程，以及固件、分区表、文件系统和引导程序各自的作用，再进入分区、挂载、安装基础系统和配置 GRUB 的实操。

指南也涵盖装好后的桌面环境、显卡驱动和 Btrfs 快照，并整理双系统常见问题。初次接触 Linux 可以先读系统结构部分。准备在已有 Windows 的电脑上实操时，应先备份数据并核对磁盘布局。
