# Git Workshop 进阶

技术部 Workshop · 2026 年夏季

## Workshop 介绍

这场 Workshop 适合已经会提交改动、切换分支的同学。课程从 Git 如何记录提交和分支开始，通过练习比较合并与变基，学习用交互式变基整理提交，以及用 `cherry-pick` 把指定提交带到另一条分支。

讲义也介绍如何用 `reflog` 找回误操作前的状态，用 `stash` 暂存未完成的改动，以及用 `worktree` 在不同目录同时处理多个分支。可以按仓库里的练习顺序动手，最后用综合练习把这些操作串起来。
