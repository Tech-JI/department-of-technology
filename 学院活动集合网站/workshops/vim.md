# Vim Workshop

技术部 Workshop · 2026 年春季

## Workshop 介绍

Workshop 从 Vim 的模式和键盘操作入手，让第一次接触 Vim 的同学知道如何在文件中移动、修改文本并保存退出。熟悉基本操作之后，可以继续练习搜索和组合编辑命令。仓库提供中英文讲义，以及插件相关的补充资料。
