# Markdown Workshop

技术部 Workshop

## Workshop 介绍

课程介绍如何使用 Markdown 组织文档，从标题、列表和链接入门，再练习插入代码块等常用内容。它适用于课程笔记、项目 README 和协作文档。可以打开仓库里的练习题，一边编辑 Markdown 源文件，一边查看渲染结果。
