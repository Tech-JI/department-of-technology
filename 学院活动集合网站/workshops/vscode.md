# Visual Studio Code Workshop

技术部 Workshop · 2025 年秋季

## Workshop 介绍

这场 Workshop 面向想把 Visual Studio Code 用作日常开发工具的同学。资料从编辑器配置和常用扩展入手，覆盖 C/C++ 环境、代码格式化、Git、Markdown 和 SSH 等场景。可以按自己当前的项目需求选读，例如先配置格式化和版本控制，再尝试远程开发。
