# Linux Install Party

技术部 Workshop

## Workshop 介绍

第一次接触 Linux，可以先比较在虚拟机中练习和在电脑上安装双系统的区别，再选择适合自己设备的方式。课程资料覆盖安装准备、系统安装和桌面使用；虚拟机路线可参考 VirtualBox 或 VMware Fusion 指南。若打算调整磁盘分区，请先备份重要文件。
