# 关于技术部

技术部是供同学们动手实践的平台，帮助大家提升工科和信息技术方面的技能。即使是第一次接触编程或技术项目，也可以从基础知识学起，再把学到的内容用到实际项目里。部门采用自由分工，成员可以按照兴趣选择参与方向。

## Workshop 宣讲

我们定期举办 Linux 安装交流活动，以及 Git、Bash、Arch Linux 等主题的 Workshop。同学们可以跟着讲义动手练习，也可以带着学习中遇到的问题来交流。

## 技术维护

技术维护组负责现有项目的运行与更新，让已经上线的工具和服务继续为同学们所用。参与维护时，你会在实际场景中积累排查和解决问题的经验。

## 项目开发

项目开发组把同学们的创意做成可以使用的工具。过去的项目包括 VS Code JOJ 插件和舞会小程序。目前正在开发选课社区，活动日历列在后续计划中。

## 宣传

宣传组负责为微信公众号「GC 蓝虎」制作技术部推送，工作包括策划选题、撰写文案、设计版式和现场拍照。你可以参与记录 Workshop、介绍项目成果，在合作中练习表达、设计和内容传播。

无论你想在代码、硬件或项目中提升技术能力，还是想尝试公众号运营、内容创作和设计，都可以从自己感兴趣的方向开始。
